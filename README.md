Front-end da NUVA, plataforma de gamificação do Challenge SoulUp que transforma ações sustentáveis (missões de
energia, água, floresta e resíduos) em SoulCoins, convertidos em crédito na conta de luz. Este repositório reúne a
Sprint 03 (migração do site estático para React) e a Sprint 04 (integração com a API Java e publicação na Vercel) da
disciplina Front-End Design Engineering (FIAP).

## Tecnologias

- React 19 (`useState`, `useEffect` e `useContext`)
- Vite
- TypeScript em modo `strict`
- Tailwind CSS v4 (breakpoints `sm`, `md`, `lg` e `xl`)
- React Router DOM
- React Hook Form
- `fetch` nativo para consumir a API
- Vercel
